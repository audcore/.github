# 声核 Audcore

轻巧的 Windows 实时调音台：连接音频设备，组合 VST3 效果器，让麦克风、伴奏和监听各走各的通道。

## 参与皮肤开发

每款皮肤在本组织的独立仓库维护。manifest.json 统一记录身份、版本、语言和构建方法，README 提供介绍及使用说明。初次收录通过资料仓库 skins.md 的 PR 人工审核；在线版本以官方签名列表为准。

声核本体源码目前不在这些公开仓库中；这里提供文档、皮肤源码和开发参考。
